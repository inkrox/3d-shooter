# 🎯 3D 枪战游戏 · 3D FPS Shooter

> ⚡ Made by **BXR** & **蓝色大肥鱼** 🐟

一个纯前端、零依赖构建的 3D 第一人称射击网页游戏。基于 **Three.js r128**（本地离线版），单文件启动即玩，支持 9 种游戏模式、13 把武器、11 张地图与完整的成长系统。

## ✨ 功能特性

- 🎮 **9 种游戏模式**：人机对战、Boss 专场、自定义战斗、训练场、丧尸生存、打靶、打金猪、商店、使用手册
- 🔫 **13 把武器**：手枪 / 冲锋枪 / 步枪 / 霰弹枪 / 狙击枪 / 火箭筒 / 左轮 / 轻机枪 / 激光步枪 / 加特林 / 火焰喷射器 / 弓弩 / 军刀
- 🗺️ **11 张地图**：草原、沙漠、雪地、霓虹夜城、工厂、海岛、丛林、太空站（低重力）、地铁站、火山熔岩（低重力）、古堡庭院
- 🌦️ **动态天气**：晴天 / 雨天 / 大雾 / 黄昏，每局随机
- 📦 **随机事件**：空投支援、敌潮涌动、补给爆发、丧尸狂潮
- 🏆 **完整成长线**：金币 → 商店永久升级 / 皮肤 → 经验等级 → 武器熟练度（Lv3 金枪）
- 📅 **任务与签到**：每日任务、7 天一轮周挑战、连续签到（最高 +350/天）
- 🏅 **成就系统**：10 个成就，解锁即送金币
- ⚙️ **手感与键位**：灵敏度 / 视野 / 震动 / 命中反馈可调，全键位自定义
- 🧱 **可破坏地形**：油桶爆炸、岩石可击碎，能跳上障碍物
- 📡 **小地图雷达**：敌人（BOSS 紫色）、队友、补给、金猪、大炮与防御阵地全标注
- 💾 **本地存档**：localStorage 持久化 + 导出/导入存档码 + 一键清空

## 🚀 快速开始

无需安装、无需构建、无需联网，双击即可游玩：

```bash
# 方式一：直接双击
3d-shooter/index.html

# 方式二：本地静态服务器（可选）
cd 3d-shooter
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

> ✅ 完全离线可用：Three.js 已内置在 `js/three.min.js`，不依赖任何 CDN。
>
> 🎮 推荐使用 **Chrome / Edge** 浏览器游玩（需要指针锁定支持）。

## 🎮 操作说明

| 按键 | 功能 |
| --- | --- |
| `W A S D` | 移动 |
| `鼠标左键` | 射击（按住连发） |
| `F`（默认） | 开镜瞄准（狙击枪全屏镜） |
| `R` / `Shift` | 疾跑 |
| `空格` | 跳跃（二段跳 / 自动翻越低矮障碍） |
| `Tab` | 蹲下 / 疾跑中滑铲 |
| `V` | 换弹 |
| `G` / `H` / `J` | 手雷 / 燃烧瓶 / 冰冻弹 |
| `T` | 操作大炮（防御阵地旁） |
| `B` | 保护罩（需购买升级） |
| `X` | 招募队友（最多 4 名） |
| `M` | 返回主菜单 |
| `Esc` | 暂停 / 继续 |
| `1-9` `0` `Q` `E` `C` | 切换武器 |

> ⌨️ 除武器键与 `Esc` 外，**所有按键都可在「设置 → 键位自定义」中修改**。

## 💰 成长系统

### 金币获取
- 击杀敌人：**+5 金币/个**（结算时）
- 得分转化：**每 20 分 = +1 金币**
- 每日首局奖励：**+200 金币**
- 每日任务 / 周挑战 / 每日签到 / 成就解锁

### 商店永久升级（跨局生效）
攻击强化 / 生命强化 / 手雷扩充 / 移速强化 / 快速换弹 / 火焰子弹 / 冰冻子弹 / 电击子弹 / 能量护盾 / 保护罩 / 消音器 / 扩容弹匣 / 光学瞄具

### 经验与等级
击杀、得分获得经验，升级提升生命上限与伤害（每级 +2%），HUD 实时显示。

### 每日任务与周挑战
- 每日 3 个任务（击杀 / 爆头 / 投掷物 / 得分），每个 **+300 金币**
- 每周 3 个挑战（7 天一轮换），每个 **+1000 金币**

### 每日签到
连续签到第 1~7 天奖励 **50 → 350 金币** 递增，断签重置。

### 成就（解锁送金币）
首杀 +100 · 50 杀 +500 · 单局 5000 分 +500 · 第 5 波 +300 · 清空猪场 +300 · 存活 120 秒 +400 · 击杀 BOSS +400 · 10 连杀 +800 · 5 级 +500 · 4 名队友 +600

## 🌦️ 环境与事件

- **天气系统**：晴天 / 雨天（粒子雨）/ 大雾（视距变短）/ 黄昏，每局随机，自定义战斗可指定

  - 🧟 **丧尸狂潮**：8 只强化丧尸
- **可破坏地形**：油桶爆炸、岩石击碎、集装箱
- **防御阵地** 🛡️：碉堡附近减伤 50% + 快速回血

## 💾 存档系统

全部存档保存在浏览器 `localStorage`：

| Key | 内容 |
| --- | --- |
| `fps_save` | 金币、商店升级、皮肤 |
| `fps_achievements` | 成就、统计、排行榜 |
| `fps_settings` | 设置、键位 |
| `fps_quests` / `fps_weekly` | 每日任务 / 周挑战 |
| `fps_checkin` | 每日签到 |
| `fps_volume` / `fps_lastgame` | 音量 / 首局奖励日期 |

- 🔄 **导出 / 导入**：商店页生成存档码，换浏览器可迁移
- 🗑️ **清空存档**：商店页底部（二次确认防误触）

## 🔧 开发者调试

游戏暴露全局调试钩子 `window.__gameDebug`，可直接在浏览器控制台使用：

```js
__gameDebug.setLocked(true)   // 强制进入指针锁定（测试用）
__gameDebug.setCoins(9999)    // 加金币
__gameDebug.spawnEnemy('boss')// 刷 BOSS
__gameDebug.killEnemy(0)      // 击杀 0 号敌人
__gameDebug.player            // 玩家对象（pos / vel / yaw / pitch）
__gameDebug.enemies           // 敌人数组
__gameDebug.state             // 全部游戏状态
```
